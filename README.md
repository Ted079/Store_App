# Store_App
Frontend e-commerce clone built with React and Redux Toolkit.
Uses fake products from Platzi Fake Store API.

🌐 Live demo (hosted on Netlify):
https://storeapp222.netlify.app/

Features:
Product search
Category filtering
Price sorting
Cart & favorites
User login / registration
Cart & favorites persisted in localStorage per user
Related products
Carousel slider

Tech Stack:
React.js · Redux Toolkit · RTK Query · Async Thunk · Axios · SCSS

About:
Pet project created to practice real-world frontend flows:
state management, API integration, cart logic, and UI features.
